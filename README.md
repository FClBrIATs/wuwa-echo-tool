# wuwa-echo-tool

装備中音骸の厳選優先度をスコアで可視化し、新規音骸と比較することが出来る私的ツールです。
単一HTMLファイルで完結し、インストール不要・サーバー不要でブラウザから即使用できます。

**対応ゲームバージョン：Ver 3.0 時点のハーモニーデータを収録**

---

## 機能一覧

### ① ステータス入力タブ
- キャラの攻撃力・HP・防御力・クリ率・クリダメ・各属性ダメバフ・スキル別ダメバフを入力
- 「合計値入力」と「項目別入力」の2モードを切り替え可能
- プリセット収録済みのハーモニーを最大2枠（2セット×2 or 手動）から選択し、バフを自動加算
- 武器・キャラ登録からの自動加算（登録済みデータをドロップダウンで選択）
- 「自動」行で各バフの内訳を確認可能
- ステータス優先度ランキング：現在のビルドに対して「攻撃力%/クリ率/クリダメ/属性ダメバフ/スキルバフ」のどれが最も期待ダメージ向上に寄与するかを表示
- クリ率:クリダメのバランス判定（目標比 1:2）

### ② 装備音骸タブ
- 装備中の音骸5スロットのコスト・メインステ・サブステ（最大5枠）を入力
- 各スロットのスコア（① のステータスを基準にした期待ダメージ貢献度）を計算・比較
- 最弱スロットを赤枠、最強スロットを緑枠でハイライト表示
- メインステはコスト選択で対応する値が自動決定・①タブのバフ計算に反映
- 音骸セットを名前を付けて保存・呼び出し（最大50件）

### ③ 新規判定タブ
- 新規入手した音骸のサブステを入力し、装備中スロット（自動 or 指定）の合格ラインと比較
- 残サブ枠で合格ラインを超える期待確率を算出
- 判定後、その場で装備中スロットを新規音骸で上書き可能

### 登録タブ（ハーモニー / 武器 / キャラ）
- ハーモニー登録：未収録のハーモニーを手動で追加し、①タブの選択肢に反映（2+5セット・3セット対応）
- 武器登録：基礎攻撃力・各バフ値を登録してドロップダウンから選択適用
- キャラ登録：キャラ固有の能力値・バフ・属性・ダメージ比率を登録して自動加算
- 登録データのJSONバックアップ／復元

## 使い方

1. `index.html` をダウンロード
2. ブラウザで開く（Chromeを推奨）
3. ① タブでキャラのステータスを入力 → ② タブで装備音骸を入力 → ③ タブで新規音骸を判定

---

## データの保存について

保存の対象範囲が項目によって異なります。

| データ | 保存 |
|--------|------|
| 登録したキャラ・武器・ハーモニー | ✅ `localStorage` に自動保存 |
| 音骸セット（②タブで名前を付けて保存したもの） | ✅ `localStorage` に保存（手動操作） |
| カードの開閉状態 | ✅ `localStorage` に自動保存 |
| **①②③タブに入力中のステータス・装備音骸** | ❌ **保存されません（リロードで消えます）** |

入力中の内容を残したい場合は、②タブの「音骸セット保存」を使ってください。
登録データは「バックアップ」からJSONとして書き出せます（入力中ステータスは対象外）。

> `localStorage` はブラウザのデータ消去で削除されます。シークレットモードでは保持されません。

## 技術仕様

- **バニラ HTML / CSS / JavaScript**（フレームワーク・ライブラリ不使用）
- **単一ファイル**完結（外部リソースはGoogleフォントのみ）
- データ永続化：`localStorage`
- スコア計算：サブステ種別ごとの**限界価値（Marginal Value）**をベースにした期待ダメージ貢献度
- 確率計算：重複なし**モンテカルロ法**（20,000試行）。値の抽選は実際の出現確率で重み付け

### サブステータスのデータについて

サブステの出現値と抽選確率は **鳴潮（めいちょう）wiki** 公開のデータを使用しています。

- サブステの「種類」は全13種から均等抽選（各 1/13 ≒ 7.6923%）
- 「値」は種類ごとの重み付き確率で抽選（例：クリ率が最大値10.5%になる確率は3.0%）
- 抽選確率は整数の重みとして保持（クリ率・クリダメは合計300、その他は合計103）

音骸スキルダメージアップはサブステとして存在しないため、抽選対象に含めていません
（ステータスとしては①タブのバフ入力欄で扱えます）。
